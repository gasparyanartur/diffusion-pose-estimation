Image picker

Create or open a custom annotation set, then choose Browse & add images. Check individual rows or choose Select page to check the visible filtered rows. Your selections carry across pages and splits. Choose Add selected to save the checked images to the set.

InputWhat it selects
64 random or random 64Up to 64 distinct images at random across all matching pages.
first 64 or last 64Up to 64 images from the start or end of the current sort order.
all matchingEvery eligible image in the current filtered result.
1–64, 100–120Inclusive, one-based positions in the open split’s original order. Sort and filters leave these positions unchanged.

Random, first, last, and all matching use the open split, active filters, and selected group. Selection skips images already queued or checked. If a command asks for more images than are available, it checks the available images and reports the count. Use Add images by ID for dataset IDs such as val/114203.

Annotation and Layers

The editor opens in Select. Choose a person’s joint or box on the image or in the sidebar. The active target shows the person, joint, and visibility. Edit starts placement for that item and returns to Select when saved. Press Delete or click Delete beside the active target to clear it. Use Move to to transfer it to another person. Delete person beside Add person removes the selected person and all their annotations. Undo restores the person.

Set joints saves one joint per click and advances to the next unfinished joint. Click Unlabeled to skip a joint explicitly. Set box saves a new bounding box after you click opposite corners.

In Edit annotations, click a joint or box to open its exact fields. Joints save each placement click and visibility change. Typed X and Y save on Enter or when you leave the coordinate fields. Click Done to pick another annotation. Boxes show Center X/Y, Width, and Height. Select Position or Size to choose what the next canvas click changes. Click Apply or press Enter to save the box. Escape discards a draft and returns to Select.

Use the work area around the photo to place, select, or edit boxes and joints beyond the image edge. Coordinates are measured from the photo’s top-left, so values can be negative or beyond its dimensions. Type coordinates for geometry farther out than the visible area.

Choose Focus mode and click a placed joint or box to zoom in 3×. Use WASD or the arrow keys to move it one image pixel per press. Undo reverses one saved change at a time, with up to 20 changes available. Press Esc to exit Focus mode. Zoom on placement is also available for one-shot edits. The 3× magnifier sits beside the photo or above it on narrow screens. It follows the pointer and coordinate adjustments, and keeps its last view while you use the sidebar. The outlined crosshair adapts to local brightness and leaves its center open. A joint draft previews edges to placed joints on the same person. For an isolated joint, the editor lists neighboring joints that can connect it.

Copy annotations from…, beside Show original labels, opens CrowdPose Ground Truth or another custom set for the same image. Check the people and choose boxes, joints, or both. Copies are added to the active set and the whole copy can be undone together.

Start the viewer with --reload to refresh automatically when web files change. The viewer waits for open dialogs and edits, then reopens the same set and image.

In Select, hover over a box or joint to highlight the person. The Layers sidebar shows the selected person and provides independent Box and Pose controls. Click a row to pin its highlight. Show original labels displays the CrowdPose reference alongside your edits. Turn on Selected person only beside Boxes and Poses to focus on the active person. Select another person from the person controls or the Layers sidebar.

Autolabeling

Open Autolabel… and choose a model and queue images. Set the person confidence threshold and, for YOLO26 Pose, the joint confidence threshold.

  • YOLO26 Boxes proposes boxes and leaves joints unfinished.
  • YOLO26 Pose proposes boxes and 12 CrowdPose limb joints. Place the head and neck manually.
  • Sapiens2 proposes boxes, the 12 limb joints, and the neck. Place the head manually.

Images with saved people or a review flag are skipped. Check visibility during review. Each result retains its initial coordinates, scores and model settings for comparison with your edits.

Source-label audit

Open Image table to filter by crowd index, people, box overlap, joint visibility, or audit tags. Click a shared-joint or outside-box flag to highlight the corresponding source annotation. Use the audit panel to record issues at image, person, or joint scope and mark completed reviews. Group counts use reviewed images as the denominator. Notes and audit tags are stored locally alongside the annotation sets.

Standards

COCO annotation format

We use one COCO JSON document per dataset split, with a manifest pointing to the existing image directory. The viewer currently edits CrowdPose poses and boxes. The standardized data also carries existing COCO masks for future segmentation work.

This example uses a two-joint person category to show the structure. CrowdPose uses its native 14 joints and COCO val2017 uses 17.

{
  "info": {
    "description": "Example pose dataset",
    "pose_graph_diff": {
      "version": 1,
      "dataset": "example",
      "split": "val",
      "source_sha256": "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"
    }
  },
  "licenses": [
    {"id": 1, "name": "CC BY 4.0", "url": "https://creativecommons.org/licenses/by/4.0/"}
  ],
  "images": [
    {"id": 8, "file_name": "000008.jpg", "width": 320, "height": 240, "license": 1}
  ],
  "categories": [
    {
      "id": 1,
      "name": "person",
      "supercategory": "person",
      "keypoints": ["left_shoulder", "left_elbow"],
      "skeleton": [[1, 2]]
    }
  ],
  "annotations": [
    {
      "id": 27,
      "image_id": 8,
      "category_id": 1,
      "bbox": [48, 35, 120, 160],
      "area": 19200,
      "iscrowd": 0,
      "keypoints": [85, 65, 2, 94, 102, 1],
      "num_keypoints": 2,
      "segmentation": [[48, 35, 168, 35, 168, 195, 48, 195]]
    }
  ]
}

Fields and coordinate conventions

FieldConvention
info, licensesDataset description and declared licenses. License records have an ID, name, and URL when supplied.
imagesEach record has an integer id, relative file_name, and pixel width and height. Keep license references, source URLs, capture dates, and CrowdPose’s crowdIndex where available.
categoriesThe category ID identifies the class. The ordered keypoints names define the array order. skeleton edges use one-based indices into that list.
annotationsEach object has its own ID and links to its image and category. iscrowd is 0 for an individual annotation or 1 for a crowd record.
bbox, areaBox as [x, y, width, height] from the top-left, in source pixels. Area is in square pixels. Keep source area when supplied. A fallback computed from the box has pose_graph_diff.area_origin set to "bbox".
keypointsFlat [x, y, v, …] triples in category order using zero-based source pixel coordinates. Use [0, 0, 0] for an unlabeled joint. Visibility 1 is labeled but occluded, and 2 is labeled and visible. num_keypoints counts both 1 and 2.

Provenance and masks

info.pose_graph_diff identifies the version of the metadata extension, dataset, split, and SHA-256 of the input JSON. Standardized records keep their native IDs, scoped by dataset and split. When a CrowdPose keypoint count changes during conversion, the original value is recorded in annotation.pose_graph_diff.source_num_keypoints. Published CrowdPose metrics use the original labels and the native evaluator.

segmentation can be a list of polygons, each a flat sequence of pixel x, y pairs, or an RLE object with size: [height, width] and counts. Uncompressed RLE is a list of alternating background and foreground run lengths in column-major order. Compressed RLE stores those runs as a string. Existing masks are carried through conversion. A missing segmentation field indicates unavailable mask data.
