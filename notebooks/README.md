# Notebooks

Notebooks are grouped by purpose:

- `investigations/` contains exploratory analyses of features, conditioning,
  architectures, and assignment behavior.
- `visualization/` contains notebooks for inspecting predictions, benchmark
  results, and qualitative pipeline behavior.
- `legacy/` contains historical experiments that are retained for reference
  but are not expected to run against the current model architecture.

Run notebooks from the repository root so relative paths to `data/`,
`results/`, and `src/` resolve consistently.
